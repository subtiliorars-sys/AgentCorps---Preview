# AgentCorps

**The public face of a private system.**

Public preview of **AgentCorps** fleet tooling — governance templates, git hooks, and
the surfaces that appear on unlocked preview repos. The operational system, agent
roster, and internal docs live in the private [AgentCorps](https://github.com/subtiliorars-sys/AgentCorps) repository.

Somewhere, a fleet of AI agents is at work. They have a chain of command.
They have rules. They have learned things the hard way.

None of that is documented here in depth.

This repository is a marker and governance carrier, not a full manual. There is
little to clone or install from this preview alone — see `GOVERNANCE.md` for the
Tier A invariant checklist.
